## 📌 Project Overview

This project explores offensive and defensive cybersecurity practices in a controlled virtual environment. It consists of three progressive phases:
1. Service exploitation
2. Security information and event management (SIEM) analysis
3. Defensive strategy implementation

All configurations, screenshots, scripts, and results are included in their respective phase folders.

## 🗂 Folder Structure

- `Phase 1/`: Service enumeration, exploitation using common tools, and a custom attack script.
- `Phase 2/`: Log collection and analysis using Splunk, demonstrating real-time SIEM capabilities.
- `Phase 3/`: A defensive mechanism was implemented and tested for effectiveness against previously observed attacks.

Each folder contains labeled screenshots (`image1.png`, `image2.png`, etc.) documenting key steps and outputs.

## 🧠 Technical Stack (General)
- Splunk (SIEM)
- Linux/Windows-based VMs
- Metasploit Framework
- fail2ban (or equivalent defensive tool)
- Bash/Python scripting
